# Jarvis Voice Assistant 🚀

A custom voice-activated desktop assistant built using Python, featuring speaker identification and AI-powered tool execution. 

*Note: I am a student developer currently building and learning Python step-by-step through this project!*

## Features
* **Speaker Recognition:** Identifies who is speaking using voice embeddings.
* **AI Tool Execution:** Handles system tasks, web searches, and file creation automatically using Groq and Gemini.
* **Screen Vision:** Can capture and analyze screen content.

## Tech Stack
* **Language:** Python
* **APIs & Libraries:** Groq SDK, Google GenAI, PyAudio, SpeechRecognition, Pyttsx3, Resemblyzer.

## How to Run
1. Clone the repository or download the files.
2. Set up your local `.env` file with your API keys.
3. Run the main script:
   ```bash
   python main.py
