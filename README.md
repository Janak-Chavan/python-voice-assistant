# Jarvis Assistant

A custom voice-activated desktop assistant built using Python.

## Features
* Recognizes voice commands.
* Uses Python and local JSON files for persistent memory.

## Tech Stack
* **Language:** Python
* **Libraries:** Speech recognition, JSON, OS modules.

## How to Run
1. Clone the repository or download the files.
2. Set up your local `.env` file with your API keys.
3. Run the main script:
   ```bash
   python main.py
